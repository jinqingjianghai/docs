### VS Code Continue Plugin

Configure the Continue extension in VS Code to use the API.

## 1. Install Extension

Search for **Continue** in VS Code Extensions and install it.

## 2. Configuration

Open the Continue settings and click "Configure" to edit the `config.json`.

If the JSON config doesn't appear automatically, open the file at:

- macOS/Linux: `~/.continue/config.json`
- Windows: `用户目录/.continue/config.json`

Paste the following content:

```json
{
  "models": [
    {
      "title": "GLM-5.1",
      "provider": "openai",
      "model": "GLM-5.1",
      "apiKey": "YOUR_API_KEY",
      "apiBase": "https://api.genbo.ai/v1"
    },
    {
      "title": "MiniMax-M2.5",
      "provider": "openai",
      "model": "MiniMax-M2.5",
      "apiKey": "YOUR_API_KEY",
      "apiBase": "https://api.genbo.ai/v1"
    }
  ],
  "tabAutocompleteModel": {
    "title": "GLM-5.1",
    "provider": "openai",
    "model": "GLM-5.1",
    "apiKey": "YOUR_API_KEY",
    "apiBase": "https://api.genbo.ai/v1"
  },
  "allowAnonymousTelemetry": false
}
```


## 3. Verify

Restart VS Code, open the Continue sidebar, and type a message. If the model responds, the configuration is successful.
